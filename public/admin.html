Spotify playlist search

Enter your Spotify Developer app credentials to enable playlist search in Request → Make a request → Playlist. These settings apply only to this WASP server.

You are using HTTP. Switch to HTTPS before entering a Spotify Client Secret so it cannot be intercepted in transit.

Sidebar credits and branding

Optional credits, links or a small logo at the very bottom of the left sidebar. The footer grows upward only as you add content. Use BBCode instead of HTML or JavaScript; blank by default.

Supported: [b]bold[/b], [i]italic[/i], [u]underline[/u], [url=https://example.com]link[/url], [img]https://example.com/logo.png[/img], [color=#C8F169]text[/color] and [center]text[/center]. Only HTTPS or same-site links/images are accepted. HTML and scripts are never executed.

Advertising

An ad shows at the top of the front page (Recently added › Songs), above the songs. Write it in HTML, CSS and JavaScript, for example a slider with clickable buttons. Only you can change it. It runs in an isolated frame, so it cannot touch the rest of the site or your admin session. Links open in a new tab; add target="_top" to a link to stay in the app. When the ad is off, the page looks as it did before.

Scheduled maintenance

Enable jobs only when needed. Each schedule runs on this WASP server, using its saved timezone. Jobs update cached information and do not remove music or playlists.

Daily jobs use a 24-hour time. Weekly jobs run on the chosen weekday at 00:00; monthly jobs run on days 1–30 at 00:00. Months without the selected day skip that month. Enabled jobs are checked every minute, with one execution per scheduled minute.
